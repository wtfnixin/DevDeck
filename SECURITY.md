# Security Policy 🛡️

## Supported Versions

We provide security updates and patches for the following versions of DevDeck:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The DevDeck team takes security seriously. If you discover a vulnerability, security flaw, or potential exploit in DevDeck (including the Desktop Agent socket server, token authentication, or native Win32 drivers), please do **NOT** open a public GitHub issue.

Instead, please report it privately:

1. **Email**: Send details to `nitinkumardontam@gmail.com` with the subject line:
   `[SECURITY] DevDeck Vulnerability Report - <Brief Summary>`
2. **GitHub Security Advisory**: Or use the private vulnerability reporting feature on GitHub via the **Security** tab of the repository.

### What to Include in Your Report
To help us resolve the issue efficiently, please include:
* Description of the vulnerability and its potential impact
* Steps to reproduce the issue (proof of concept script or sequence of events)
* Affected platform (Windows Desktop Agent, Flutter Android App, Web client)
* Any proposed mitigations or fixes if you have one

---

## Response Timeline

* **Acknowledgment**: We aim to acknowledge receipt of security reports within **48 hours**.
* **Assessment & Fix**: We will work to verify and develop a patch as quickly as possible.
* **Public Disclosure**: Once a fix is released in a new version, we will coordinate public disclosure and credit you for the responsible disclosure.

Thank you for helping keep DevDeck and its users safe! 🔒
